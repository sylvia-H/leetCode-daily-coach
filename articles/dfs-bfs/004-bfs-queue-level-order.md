## Concept

廣度優先搜尋（BFS）是圖搜尋的第二副骨架。先前的 DFS 靠遞迴（或堆疊）沿一條路鑽到底；BFS 則把「發現節點」和「處理節點」拆開，中間用一個佇列（Queue）排隊：發現時放進隊尾，處理時從隊首取出。整套流程只有四步——起點入隊並標記已造訪；只要佇列非空就取出隊首 u；走訪 u 的每個鄰居 v，凡未標記者先標記再入隊；佇列清空即結束。

先把度量講清楚。起點到節點 v 的**距離**是連接兩者所需的最少邊數。BFS 另外給每個節點記一個**層數**：起點 0，被層數 d 的節點發現的鄰居記 d + 1，且**只在入隊當下記一次**（這就是「入隊當下就標記」的前提）。在這個前提下，BFS 的全部價值來自一條迴圈不變式：佇列中的節點依層數由小到大排列，且隊首與隊尾的層數相差不超過 1。

誠實定位：你在佇列模組的「Queue BFS Level Order Traversal」已經用「佇列 + 層長快照」解過層序走訪，也在該模組的下一課用佇列求過無權圖最短路。本課不換題目，而是回到圖搜尋的脈絡，把「為什麼非得是佇列」論證到底：換成堆疊，同一份程式碼會得到什麼；標記時機比 DFS 嚴格在哪裡。

## Thinking

**不變式為何成立。** 用歸納法。初始佇列只有層數 0 的起點，成立。設某一刻成立，取出的隊首 u 層數為 d，是佇列中最小者；u 發現的鄰居全記為 d + 1、接在隊尾，而原本的隊尾至多是 d + 1，所以「由小到大」與「首尾差不超過 1」都保住。推論：出隊順序的層數非遞減——這正是先修課「淺的先出」的精確版本。層數是不是真正的最短距離？光有非遞減還不夠，得再補一段歸納，證明留到最短路徑那一課；本課先把佇列的秩序證穩。

**FIFO 的角色就在「接在隊尾」這一步。** 不變式只用到佇列的兩個性質：取出的是最早放入的、放入的接在最後。把容器換成堆疊（後進先出），最後放入的先取出，層數 d + 1 的節點會插到層數 d 的節點之前，「由小到大」立刻失效。Python Tip 用同一份程式碼、只改取出端做對照：六個節點的圖，FIFO 的處理順序是 0,1,2,3,4,5（層數 0,1,1,2,2,3），LIFO 則是 0,2,4,5,3,1——層數 3 的節點 5 排在層數 1 的節點 1 之前。

**標記時機比 DFS 嚴格。** 遞迴 DFS 在「進入節點時」標記就夠，因為發現與處理是同一瞬間。BFS 把兩者拆開，若等到出隊才標記，同一個節點在首次出隊前可能被多個鄰居各放入一次：三角形圖 0–1–2 從 0 出發，0 放入 1 和 2，接著 1 出隊時 2 尚未標記、再被放入一次；入隊次數從 3 變 4，且層長快照會多切出一個空層——拿層數當深度就多 1。所以 BFS 的標記必須跟著「發現」走，也就是入隊當下。

**分層。** 不變式保證佇列裡最多橫跨相鄰兩層，因此先修課的層長快照直接沿用：外層每輪開始時佇列恰好是完整的一層，記下長度 size，內層剛好取出 size 個。

## Pattern Recognition

三個訊號：題目要求逐層輸出或對每層做聚合；要求「最少步數」且每步代價相同；需要按層分組的結構性質。第三個訊號值得記住：由不變式可推出，**無向圖中任一條邊的兩端層數最多相差 1**——u 出隊時若 v 未標記，v 記為 d + 1；若已標記，它是被更早出隊、層數不超過 d 的節點發現的，層數不超過 d + 1；u、v 對調同理。這條性質之後在二分圖判定會用到。反之，題目關心的是一條完整路徑（路徑總和、枚舉所有解）時，DFS 更貼合。

## Common Mistakes

每一條都由 TypeScript Tip 的程式碼施加單一改動實測：

- **用堆疊取代佇列**：把 `q[head++]` 改成 `q.pop()`，六節點圖的分層從 `[[0],[1,2],[3,4],[5]]` 變成 `[[0],[2,4],[5,3,1]]`——層數 3 的 5 和層數 1 的 1 被分到同一組。
- **內層迴圈用即時長度**：把 `i < size` 改成 `i < q.length - head`，得 `[[0,1],[2,3],[4],[5]]`——剛入隊的節點被混進當前層。
- **沒有標記已造訪**：刪掉 `seen[v] = true;`，在含環的圖上永不終止；實測各層元素數 1,2,3,8,14,36,64… 指數成長，到第 14 層佇列已超過五萬。樹沒有環、每個節點只有唯一來路才可省略；一般圖不行。

## Complexity

時間 O(V + E)：入隊當下標記保證每個節點至多入隊、出隊各一次，貢獻 O(V)；每條邊在其兩端出隊時各被檢查一次，貢獻 O(E)。空間 O(V)：visited 佔 O(V)；佇列最多同時裝著相鄰兩層，最寬的一層在完全二元樹的底層接近 V / 2，仍是 O(V)。用讀取索引取代 `shift()`，可避免每次出隊搬移整個陣列、最壞退化成 O(V^2)。

## Digest

BFS 用佇列把「發現」與「處理」拆開：起點入隊並標記；取出隊首、把未標記的鄰居先標記再放到隊尾；佇列清空即結束。每個節點在入隊當下記一次層數（起點 0，被層數 d 的節點發現者記 d + 1）。核心不變式——**在鄰居入隊當下就標記、層數只記一次的前提下**，佇列內節點的層數由小到大、首尾相差不超過 1——用歸納法可證，而它只依賴 FIFO 的「取最早、接最後」；換成堆疊，層數 3 的節點會排到層數 1 的節點之前。層數是否等於最短距離，光有非遞減還不夠、得再補一段歸納，留到最短路徑那一課證明。標記必須跟著發現走（入隊當下），否則同一節點會重複入隊、多切出空層。分層沿用層長快照：外層每輪開始時佇列恰好是一整層。推論：無向圖中任一條邊的兩端最多相差一層。時間 O(V + E)、空間 O(V)。

## TypeScript Tip

讀取索引 `head` 取代 `shift()`，出隊 O(1)；`q[head++]!` 的非空斷言由快照保證。

```typescript
import { strict as assert } from "node:assert";

function bfsLevels(adj: number[][], start: number): number[][] {
  const seen: boolean[] = [], q = [start], out: number[][] = [];
  seen[start] = true;
  let head = 0;
  while (head < q.length) {
    const size = q.length - head, level: number[] = [];   // 層長快照
    for (let i = 0; i < size; i++) {
      const u = q[head++]!; level.push(u);
      for (const v of adj[u] ?? []) if (!seen[v]) { seen[v] = true; q.push(v); }
    }
    out.push(level);
  }
  return out;
}

const g = [[1, 2], [0, 3], [0, 3, 4], [1, 2, 5], [2, 5], [3, 4], []];
assert.deepEqual(bfsLevels(g, 0), [[0], [1, 2], [3, 4], [5]]);
assert.deepEqual(bfsLevels(g, 6), [[6]]);
```

## Python Tip

同一份程式碼，只把取出端從 `popleft()` 換成 `pop()`，逐層順序就崩了；`deque` 兩端操作都是 O(1)。

```python
from collections import deque

def traverse(adj: dict[int, list[int]], start: int, lifo: bool) -> list[int]:
    seen, box, order = {start}, deque([start]), []
    while box:
        u = box.pop() if lifo else box.popleft()   # 唯一差別：從哪一端取
        order.append(u)
        for v in adj[u]:
            if v not in seen:
                seen.add(v); box.append(v)
    return order

g = {0: [1, 2], 1: [0, 3], 2: [0, 3, 4], 3: [1, 2, 5], 4: [2, 5], 5: [3, 4]}
assert traverse(g, 0, lifo=False) == [0, 1, 2, 3, 4, 5]  # 層數 0,1,1,2,2,3：逐層
assert traverse(g, 0, lifo=True) == [0, 2, 4, 5, 3, 1]   # 層數 3 的 5 先於層數 1 的 1
```

## Takeaway

BFS 靠 FIFO 維持「佇列內層數由小到大、首尾差不超過 1」，標記跟著入隊走，逐層擴散才成立。
