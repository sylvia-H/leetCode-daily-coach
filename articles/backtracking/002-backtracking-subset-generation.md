## Concept

昨天已經用 `bt(start)`「從 `start` 往後挑」把 78 Subsets 解完，也證明過它不重不漏。今天不換題，換樹：**對每個索引只問一個是非題——取，或不取**。定義 `bt(i)`，`i` 是「現在輪到誰做決定」；它恰有兩個孩子：把 `nums[i]` push 進 `path` 後呼叫 `bt(i + 1)`（取），pop 掉再呼叫一次 `bt(i + 1)`（不取）。走到 `i === n` 時每個元素都決定過了，此刻的 `path` 就是一個子集，存一份拷貝。

這是一棵深度 n 的**滿二元樹**：第 i 層的節點代表「前 i 個元素已決定、其餘未定」的部分解，葉節點恰有 2^n 片。正確性靠一個對應：**每片葉子 ↔ 一條長度 n 的取／不取序列 ↔ 一個子集**。兩片不同的葉子至少在某個索引上決定相反，所以子集不同（不重複）；任何子集都能寫成一條取／不取序列，而樹裡每條序列都有葉子（不遺漏）。昨天的不變式沒變：`bt` 返回時 `path` 與進入時相同——所以取分支的 push 必須在走不取分支之前 pop 掉。

兩棵樹給同一份答案，差在**收集時機**。`start` 樹的 2^n 個節點各是一個子集，所以進入就收；取／不取樹只有 2^n 片葉子是子集，內部節點是「還沒決定完」的半成品，所以**只在葉節點收**。這就是本課的 exit criteria：知道自己站在哪棵樹上，就知道該在節點還是葉節點收。

## Thinking

給 `[1, 2, 3]`，追蹤 `bt(0)`：取 1 → `bt(1)`，取 2 → `bt(2)`，取 3 → `bt(3)`，`i === n`，存 `[1, 2, 3]`。pop 3、不取 3 → `bt(3)` 存 `[1, 2]`。回到 `bt(1)`：pop 2、不取 2 → `bt(2)`：取 3 存 `[1, 3]`，不取存 `[1]`。回到 `bt(0)`：pop 1、不取 1 → 同樣走完得 `[2, 3]、[2]、[3]、[]`。八片葉子，順序是「先取後不取」的深度優先序，空集是最後一片——與昨天空集第一個出現正好相反。

葉子既然是一條 n 位的取／不取序列，就能寫成一個 n 位元整數：第 i 位是 1 代表取 `nums[i]`。於是遞迴可以攤平成迴圈：`mask` 從 0 跑到 `2^n - 1`，每個 `mask` 拼出一個子集，同樣不重不漏。這個 **bitmask 版**沒有遞迴、沒有 pop，n ≤ 20 時很好用；但它只是取／不取樹的攤平，不是另一種想法。

兩棵樹怎麼對應？`start` 樹在某一層「選 `i`」，等於取／不取樹裡「不取 `start`…`i - 1`、再取 `i`」這一連串決定被壓成一條邊；`start` 樹的迴圈跑完不再選，就是取／不取樹一路不取到底走到葉子。所以 `start` 樹是把取／不取樹的「不取」鏈壓縮後的樣子：每個節點都對應到一片「其餘全部不取」的葉子，這正是它能在每個節點收集的原因；換來的是節點數從 `2^(n+1) - 1` 降到 2^n，代價是樹的分支數不再固定為 2。

什麼時候選哪棵樹？取／不取樹的分支不依賴「往後挑」，當每個元素的決定不只二選一（可取 0、1、2 份）、或答案要等所有元素決定完才成立（湊到某個和、比對長度）時最自然；`start` 樹每個節點都是合法解、候選集隨 `start` 縮小，適合組合與剪枝——明天的去重剪枝就是在它上面做。

## Pattern Recognition

看到「所有子集／冪集」「每個元素各自獨立決定要不要」「列出所有長度的組合」，就是這個 Pattern；輸出量 2^n 是線索，題目的 n 通常 ≤ 20。若部分解本身就是答案、或要沿 `start` 剪枝，用 `start` 樹；若要等全部決定完才能判斷、或每個元素有多種份數，用取／不取樹。

## Common Mistakes

第一，**在取／不取樹的每個節點都收集**。`[1, 2, 3]` 會得到 15 筆（`2^(n+1) - 1` 個節點）而非 8 筆：`[]` 出現 4 次、`[1, 2]` 出現 2 次——內部節點是半成品。第二，反過來**在 `start` 樹只在 `start === n` 收集**：只有最後一步選了 `nums[n - 1]` 的路徑才走得到，`[1, 2, 3]` 只剩 `[1, 2, 3]、[1, 3]、[2, 3]、[3]` 四筆。第三，**取分支回來沒 pop 就走不取分支**：不取分支繼承了上一支的元素，8 筆變成 `[1, 2, 3]、[1, 2, 3]、[1, 2, 3, 3]…`，數量對、內容錯。第四，**基底條件寫成 `i === n - 1`**：最後一個元素永遠沒被決定，只剩 `[1, 2]、[1]、[2]、[]` 四筆。第五，昨天講過的存參考而非拷貝：葉節點 `res.push(path)` 會得到 8 個指向同一個、最後被 pop 空的陣列。

## Complexity

取／不取樹有 `2^(n+1) - 1` 個節點，每個節點 O(1)，葉節點另花 O(n) 存拷貝，所以時間 O(n · 2^n)；課程標籤的 O(2^n) 指葉子數。bitmask 版同樣 O(n · 2^n)。額外空間 O(n)：遞迴深度 n + 1、`path` 長度最多 n，輸出本身不計入。

## Digest

同一棵子集樹的第二種切法：`bt(i)` 對索引 i 只問「取或不取」——push、`bt(i + 1)`、pop、再 `bt(i + 1)`。這是深度 n 的滿二元樹，每片葉子 ↔ 一條取／不取序列 ↔ 一個子集，所以 2^n 片葉子不重不漏。與昨天 `start` 樹的差別只在收集時機：`start` 樹每個節點都是子集，進入就收；取／不取樹只有葉節點（`i === n`）是子集，內部節點是半成品，只在葉節點收。葉子即 n 位元整數，攤平成 `mask` 從 0 到 `2^n - 1` 的迴圈就是 bitmask 版。常見錯誤：每個節點都收（15 筆）、取分支後沒 pop（內容錯）、基底寫成 `n - 1`（漏掉最後一個元素）。時間 O(n · 2^n)、額外空間 O(n)。

## TypeScript Tip

只在 `i === nums.length` 收拷貝；測資驗證內容與順序，所以每個節點都收、沒 pop、基底寫錯都會被斷言抓到。

```typescript
import { strict as assert } from 'node:assert';

function subsets(nums: number[]): number[][] {
  const res: number[][] = [];
  const path: number[] = [];
  const bt = (i: number): void => {
    if (i === nums.length) { res.push([...path]); return; } // 葉節點才收
    path.push(nums[i]!); // 取
    bt(i + 1);
    path.pop();          // 先還原，再走不取
    bt(i + 1);           // 不取
  };
  bt(0);
  return res;
}

assert.deepEqual(subsets([1, 2, 3]),
  [[1, 2, 3], [1, 2], [1, 3], [1], [2, 3], [2], [3], []]);
assert.deepEqual(subsets([]), [[]]); // 唯一的葉子就是根
```

## Python Tip

遞迴版與 bitmask 版是同一棵樹：`m >> i & 1` 就是第 i 個元素「取或不取」。

```python
def subsets(nums: list[int]) -> list[list[int]]:
    res: list[list[int]] = []
    path: list[int] = []

    def bt(i: int) -> None:
        if i == len(nums):
            res.append(path[:])  # 葉節點才收拷貝
            return
        path.append(nums[i])  # 取
        bt(i + 1)
        path.pop()            # 還原後才走不取
        bt(i + 1)

    bt(0)
    return res

def subsets_mask(nums: list[int]) -> list[list[int]]:
    n = len(nums)
    return [[nums[i] for i in range(n) if m >> i & 1] for m in range(1 << n)]

assert subsets([1, 2, 3]) == [[1, 2, 3], [1, 2], [1, 3], [1], [2, 3], [2], [3], []]
assert sorted(subsets_mask([1, 2, 3])) == sorted(subsets([1, 2, 3]))
```

## Takeaway

取／不取樹只有葉節點是子集，所以走到 `i === n` 才收；`start` 樹每個節點都是子集，進入就收。
